# Choose a trusted CLI source / 信頼できるCLIを選択

**English:** Prefer `codex` from `PATH`. You can explicitly opt in to an
available official OpenAI extension bundle, or configure an absolute path only
for an executable you trust.

**日本語:** `PATH`上の`codex`を推奨します。利用可能な公式OpenAI拡張機能の
同梱版へ明示的にオプトインするか、信頼できる実行ファイルだけを絶対パスで設定します。

Every resolved executable is fingerprinted before use. / 解決した実行ファイルは、
使用前にフィンガープリントを確認します。
