# Open a saved Markdown note / 保存済みMarkdownノートを開く

**English:** Add a heading such as `# Hamiltonian simulation`. By default, only
empty sections at the configured heading level are selected.

**日本語:** `# ハミルトニアンシミュレーション`のような見出しを追加します。
既定では、設定した見出しレベルの空セクションだけを選択します。

Unselected text stays outside the generated edit ranges. / 未選択の本文は生成編集の
範囲外です。
